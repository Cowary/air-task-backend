# Журнал действий агентов в веб-настройках

## Цель

Проверить раздел «Журнал действий агентов» на экране настроек: отображение вызовов
MCP-инструментов и обновление списка.

## Предусловия

- Dev-фронт доступен: `http://192.168.1.77:5174`.
- Вход выполнен пользователем `ruderu` / `12345678`.
- В журнале есть записи от ключа `opencode-test`.

## Компоненты и инструменты

| Компонент | Инструмент |
|---|---|
| Frontend | Playwright |
| Backend | MCP airtask-test |

## Сценарий 1 — Отображение записей журнала

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, MCP airtask-test

### Шаги

1. Вызвать `idea_create` с именем `MCP-Test-Audit-Web` через MCP.
2. Открыть `/settings` и раздел «Журнал действий агентов».
3. Проверить строку с инструментом `idea_create`.

### Ожидаемый результат

Строка содержит время, ключ `opencode-test`, `idea_create`, статус `SUCCESS`, длительность в мс.

## Сценарий 2 — Ошибка и обновление списка

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, MCP airtask-test

### Шаги

1. Вызвать `project_create` с неверным `status` = `BOGUS`.
2. Нажать «Обновить» в разделе журнала.
3. Проверить строку с инструментом `project_create`.

### Ожидаемый результат

Строка `project_create` отображается со статусом `ERROR` и красным бейджем.
