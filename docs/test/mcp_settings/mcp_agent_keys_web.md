# Управление MCP-ключами в веб-настройках

## Цель

Проверить раздел «Агенты (MCP)» на экране настроек: список ключей, создание ключа
с одноразовым показом и отзыв.

## Предусловия

- Dev-фронт доступен: `http://192.168.1.77:5174`.
- Вход выполнен пользователем `ruderu` / `12345678`.
- Backend и MCP-сервер доступны.

## Компоненты и инструменты

| Компонент | Инструмент |
|---|---|
| Frontend | Playwright |

## Сценарий 1 — Отображение раздела и списка ключей

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. Открыть страницу `/settings` и войти под `ruderu`.
2. Прокрутить до раздела «Агенты (MCP)».
3. Проверить адрес MCP-сервера и таблицу ключей.

### Ожидаемый результат

Виден адрес MCP-сервера; таблица содержит ключ `opencode-test` со статусом «Активен».

## Сценарий 2 — Создание ключа с одноразовым показом

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. Нажать «Создать ключ» и ввести имя `MCP-Test-Key`.
2. Нажать «Создать» и дождаться модалки «Ключ создан».
3. Скопировать значение ключа и нажать «Готово».

### Ожидаемый результат

Модалка показывает полный ключ `atk_...`; после закрытия ключ в списке только по префиксу.

## Сценарий 3 — Отзыв ключа

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. Нажать «Отозвать» у ключа `MCP-Test-Key`.
2. Подтвердить во модалке «Отозвать ключ?».
3. Проверить статус в таблице.

### Ожидаемый результат

Статус ключа становится «Отозван»; кнопка отзыва исчезает.
