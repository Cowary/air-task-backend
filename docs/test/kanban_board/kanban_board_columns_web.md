# Раскладка карточек канбан-доски по колонкам

## Цель

Проверить, что канбан-доска `/workspace` (вкладка «Канбан») раскладывает обычные,
еженедельные задачи и напоминания по шести колонкам согласно их сроку.

## Предусловия

- Frontend Air Task v1.19.1 запущен; пользователь авторизован.
- Backend доступен, контейнеры backend и БД запущены (проверить через MCP Docker).
- Через curl подготовлены задачи со сроками: вчера, сегодня, завтра, конец недели, конец месяца.
- Подготовлены еженедельная задача (IN_PROGRESS) и напоминание с ближайшей датой сегодня.
- Системная дата браузера не меняется; все даты задач вычисляются от неё.

## Компоненты и инструменты

| Компонент | Инструмент |
|---|---|
| Frontend | Playwright |
| Backend | curl |
| Docker | MCP Docker |

## Сценарий 1 — Раскладка задач по датам

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl, MCP Docker

### Шаги

1. Проверить через MCP Docker, что контейнеры backend и БД запущены.
2. Создать через curl задачи со сроками вчера, сегодня, завтра, конец недели, конец месяца.
3. Открыть в Playwright `/workspace?tab=kanban` и дождаться загрузки доски.
4. Проверить, что каждая задача стоит в колонке своего срока.
5. Сверить счётчики в заголовках колонок с числом карточек.

### Ожидаемый результат

Просроченная задача — в «Просрочено», сегодняшняя — в «Сегодня», завтрашняя — в
«Завтра», задача конца недели — в «На этой неделе», конца месяца — в «В этом
месяце»; счётчики колонок соответствуют количеству карточек.

## Сценарий 2 — Еженедельные задачи в отдельной колонке

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Создать через curl еженедельную задачу со статусом IN_PROGRESS.
2. Перезагрузить доску канбана в Playwright.
3. Найти карточку в колонке «Еженедельные».
4. Убедиться, что карточка не появилась в колонках по дате.
5. Проверить у карточки метку «до конца недели».

### Ожидаемый результат

Еженедельная задача показана в колонке «Еженедельные» с датой окончания недели и
меткой «до конца недели»; в колонках по дате её нет.

## Сценарий 3 — Напоминания по ближайшей дате

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Создать через curl напоминание с ближайшей датой сегодня.
2. Перезагрузить доску канбана в Playwright.
3. Найти карточку напоминания в колонке «Сегодня».
4. Проверить тип карточки «Напоминание» и её дату.

### Ожидаемый результат

Напоминание с датой сегодня показано в колонке «Сегодня» как карточка типа
«Напоминание» с датой в формате дд.мм.гггг.

## Сценарий 4 — Завершённые, без срока и вне месяца скрыты

**Тип:** Негативный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Создать через curl выполненную задачу со сроком сегодня.
2. Создать задачу без срока и задачу со сроком в следующем месяце.
3. Завершить через curl напоминание с ближайшей датой сегодня.
4. Перезагрузить доску и найти карточки этих сущностей.
5. Убедиться, что перечисленные записи не отображаются на доске.

### Ожидаемый результат

Выполненные задачи, задачи без срока, задачи за пределами текущего месяца и
завершённые напоминания на доске отсутствуют.
