# Карточки, приоритет и взаимодействие канбан-доски

## Цель

Проверить, что карточки канбан-доски различаются по типу и цвету, показывают
приоритет, открывают нужную модалку и сортируются внутри колонки.

## Предусловия

- Frontend Air Task v1.19.1 запущен; пользователь авторизован.
- Backend и БД запущены (проверить через MCP Docker).
- Подготовлены задачи: с проектом, без проекта, с приоритетами HIGH, MIDDLE, LOW.
- Подготовлены еженедельная задача и напоминание с датой сегодня.
- Ширина окна больше 600 px, чтобы легенда была видна.

## Компоненты и инструменты

| Компонент | Инструмент |
|---|---|
| Frontend | Playwright |
| Backend | curl |
| Docker | MCP Docker |

## Сценарий 1 — Типы карточек и легенда

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Открыть в Playwright `/workspace?tab=kanban` и дождаться доски.
2. Проверить в легенде четыре пункта: Проект, Без проекта, Еженедельные, Напоминания.
3. Убедиться, что задача проекта имеет класс card-project-task.
4. Убедиться, что задача без проекта имеет класс card-plain-task.
5. Проверить классы card-weekly и card-reminder у соответствующих карточек.

### Ожидаемый результат

Каждой сущности соответствует свой цвет и класс карточки; легенда содержит все
четыре типа — Проект, Без проекта, Еженедельные, Напоминания.

## Сценарий 2 — Приоритет карточки

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Найти на доске карточку задачи с приоритетом HIGH.
2. Проверить метку «Высокий» и класс priority-high у карточки.
3. Найти карточки с приоритетами MIDDLE и LOW.
4. Убедиться в наличии меток «Средний» и «Низкий».

### Ожидаемый результат

HIGH показан меткой «Высокий», MIDDLE — «Средний», LOW — «Низкий»; метка
подсвечена цветом соответствующего приоритета.

## Сценарий 3 — Клик по карточке открывает нужную модалку

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. Нажать на карточку задачи проекта.
2. Проверить открытие модалки редактирования задачи с её названием.
3. Закрыть модалку и нажать на карточку еженедельной задачи.
4. Проверить открытие модалки еженедельной задачи.
5. Нажать на карточку напоминания и проверить его модалку.

### Ожидаемый результат

Клик по карточке задачи открывает модалку задачи, по еженедельной — модалку
еженедельной задачи, по напоминанию — модалку напоминания.

## Сценарий 4 — Сортировка внутри колонки

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Создать через curl две задачи с одинаковым сроком сегодня.
2. Назвать их «Омега» и «Альфа».
3. Перезагрузить канбан и открыть колонку «Сегодня».
4. Убедиться, что «Альфа» стоит выше «Омеги».

### Ожидаемый результат

Карточки с одинаковым сроком отсортированы по названию в порядке русского
алфавита: «Альфа» выше «Омеги».
