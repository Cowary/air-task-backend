# Состояния, диапазон недели и ошибки канбан-доски

## Цель

Проверить, что шапка канбана показывает диапазон недели по настройке первого дня,
пустые колонки помечаются «Пусто», а ошибка загрузки данных показывает повтор.

## Предусловия

- Frontend Air Task v1.19.1 запущен; пользователь авторизован.
- Backend и БД запущены (проверить через MCP Docker); доступен `/api/settings/v1`.
- Для сценария 2 на стенде нет активных карточек канбана.

## Компоненты и инструменты

| Компонент | Инструмент |
|---|---|
| Frontend | Playwright |
| Backend | curl |
| Docker | MCP Docker |

## Сценарий 1 — Диапазон недели по первому дню

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright, curl

### Шаги

1. Установить через curl `firstDayOfWeek=SUNDAY` в PUT /api/settings/v1.
2. Открыть `/workspace?tab=kanban` и прочитать диапазон недели в шапке.
3. Проверить, что дата начала приходится на воскресенье.
4. Установить `firstDayOfWeek=MONDAY` и перезагрузить доску.
5. Проверить, что дата начала приходится на понедельник.
6. Вернуть `firstDayOfWeek=SUNDAY` через curl.

### Ожидаемый результат

Диапазон «с … по …» начинается с воскресенья при SUNDAY и с понедельника при
MONDAY; дата конца отстоит от начала на шесть дней.

## Сценарий 2 — Пустые колонки

**Тип:** Позитивный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. Обеспечить отсутствие активных задач, еженедельных задач и напоминаний.
2. Открыть `/workspace?tab=kanban` в Playwright.
3. Проверить, что все шесть колонок отображаются.
4. Убедиться, что в каждой колонке показан текст «Пусто».
5. Проверить, что счётчики всех колонок равны нулю.

### Ожидаемый результат

Отображаются шесть колонок с заглушкой «Пусто» и нулевыми счётчиками карточек.

## Сценарий 3 — Ошибка загрузки и повтор

**Тип:** Негативный
**Компонент:** frontend
**Инструменты:** Playwright

### Шаги

1. В Playwright перехватить `/api/weekly/v1/list` ответом 500.
2. Открыть `/workspace?tab=kanban`.
3. Проверить появление блока ошибки «Не удалось загрузить часть данных доски.»
4. Снять перехват и нажать кнопку «Повторить».
5. Убедиться, что доска отрисовалась и блок ошибки исчез.

### Ожидаемый результат

При сбое загрузки weekly/reminders показан блок с ошибкой и кнопкой «Повторить»;
после снятия сбоя и повтора доска загружается, блок ошибки исчезает.
